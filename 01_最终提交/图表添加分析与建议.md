### ⭐⭐⭐ 最高优先级 —— 财务数据可视化（§7 财务计划）

当前 §7 有大量数字表格（利润表、资产负债表、现金流量表、收入结构表、成本结构表），但**全部是纯表格**，读者很难一眼看出趋势和对比。这是整个商业计划书中最需要图表的地方。

#### 📊 图 A1：五年收入结构堆叠柱状图

- **位置**：§7.2 收入与成本预算 —— 收入结构预测表之后
- **数据来源**：收入结构预测表（180 / 620 / 1560 / 3280 / 6100 万元）
- **图表类型**：堆叠柱状图（Stacked Bar Chart）
- **生成工具**：✅ **Seaborn**
- **数据说明**：5 根柱子（2027–2031），每根按收入来源分色堆叠（整机销售 / 设备租赁 / 地图建设 / 运维平台 / 导览其他）
- **亮点**：直观展示收入从 180 万 → 6100 万的爆发式增长，以及收入结构从"硬件主导"向"服务主导"的演变

---

#### 📊 图 A2：收入-成本-利润趋势折线图

- **位置**：§7.3 利润表预测 —— 利润表之后
- **数据来源**：利润表（营业收入 / 营业成本 / 净利润）
- **图表类型**：多线折线图（Multi-line Chart）+ 半透明面积填充
- **生成工具**：✅ **Seaborn**
- **数据说明**：X 轴 2027–2031，3 条线（营业收入 / 营业成本 / 净利润），净利润区域用半透明色块填充
- **亮点**：清晰展示盈亏平衡拐点（2028 年扭亏为盈），净利润加速增长

---

#### 📊 图 A3：成本费用结构堆叠柱状图

- **位置**：§7.2 —— 成本费用结构预测表之后
- **数据来源**：成本费用结构表
- **图表类型**：堆叠柱状图
- **生成工具**：✅ **Seaborn**
- **数据说明**：营业成本 / 销售费用 / 管理费用 / 研发费用 四项堆叠
- **亮点**：展示研发费用占比逐年下降、规模效应显现

#### 📊 图 A4：融资资金用途环形图

- **位置**：§7.6 融资需求与资金用途 —— 资金用途表之后
- **数据来源**：300 万元融资用途表（95 / 55 / 50 / 35 / 35 / 30 万）
- **图表类型**：环形图（Donut Chart）或 旭日图（Sunburst）
- **生成工具**：✅ **Seaborn/Matplotlib**
- **数据说明**：6 项用途的占比（研发升级 / 市场推广 / 生产备货 / 团队扩建 / 运营储备 / 其他）

#### 📊 图 A6：现金流趋势图

- **图表类型**：分组柱状图（Grouped Bar）+ 期末现金余额折线
- **生成工具**：✅ **Seaborn**
- **数据说明**：经营 / 投资 / 筹资三类现金流净额 + 期末现金余额趋势线

### Seaborn/Matplotlib（Python 数据可视化）

| 维度 | 评分 | 说明 |
|------|------|------|
| **数据精确性** | ⭐⭐⭐⭐⭐ | 100% 精确，直接绑定数据源，不会"编造"数字 |
| **图表多样性** | ⭐⭐⭐⭐⭐ | 折线/柱状/堆叠/雷达/热力/气泡/饼图/瀑布图，应有尽有 |
| **可复现性** | ⭐⭐⭐⭐⭐ | 代码一次写好，数据更新后一键重新生成 |
| **专业感** | ⭐⭐⭐⭐ | 配合 seaborn 主题样式 + 自定义调色板，可达到学术期刊/顶级咨询报告水准 |
| **立体感/3D** | ⭐⭐⭐ | Matplotlib 有 3D 模块可做 3D 柱状图，但效果不如专业 3D 软件 |
| **中文支持** | ⭐⭐⭐ | 需配置中文字体（SimHei / Songti SC），一次性配置后可复用 |
| **最佳用途** | 所有数据驱动型图表（财务/统计/对比/趋势） | |

**推荐调色板方案（大气高端风格）：**
- `seaborn.color_palette("mako")` —— 深海蓝紫渐变，科技感强
- `seaborn.color_palette("rocket")` —— 暖色深色调，高端商务感
- 自定义：深蓝 `#1a365d` + 金色 `#d4a574` + 青色 `#2d9cdb` —— 科技 + 金融风
- 配合 `sns.set_style("darkgrid")` + 暗色背景，立体感和高级感立现

### GPT Image（AI 图像生成）

| 维度 | 评分 | 说明 |
|------|------|------|
| **视觉冲击力** | ⭐⭐⭐⭐⭐ | 可生成照片级真实感、3D 渲染、玻璃质感等震撼视觉效果 |
| **数据精确性** | ⭐ | **致命缺陷**——AI 会"编造"数字、标签错位、比例失衡 |
| **可复现性** | ⭐⭐ | 每次生成结果不同，难以微调 |
| **创意自由度** | ⭐⭐⭐⭐⭐ | 概念插画/场景渲染/未来愿景，创意无上限 |
| **中文文字** | ⭐⭐ | AI 生成中文经常出错、字形扭曲 |
| **一致性** | ⭐⭐ | 多张图之间的风格一致性难以保证 |
| **最佳用途** | 概念插图/场景渲染/封面设计/情感化表达 | |

## 五、现有 TikZ 示意图诊断与改造方案

当前文档中共有 **6 处 TikZ 手绘示意图**，逐一诊断如下。

---

### 🔴 TikZ #1：产品总体构成示意图（§2.2）

**现状问题：**
- 纯黑白灰，`fill=gray!12`，毫无色彩
- 5 个方块围绕中间，缺乏层次感
- 箭头是普通黑色实线，无粗细变化
- 看起来像草稿，不像商业文档的图

**改造方案：✅ 保留并升级 TikZ**
- 中心节点用深蓝渐变 + 白色文字
- 外围 5 个节点各用不同颜色（激光雷达 = 科技蓝、视觉 = 青色、手柄 = 暖橙、语音 = 绿色、云端 = 紫色）
- 使用 `shadows.blur` 库添加阴影，产生浮起立体感
- 箭头加粗并用渐变色
- 加一个浅色背景圆角矩形底板，让整图更有"卡片"感

> **备选：** 也可用 GPT Image 生成 3D 立体爆炸图（中心机器人 + 5 个模块环绕），更炫但失去 LaTeX 原生优势。

---

### 🔴 TikZ #2：核心技术路线示意图（§2.4）

**现状问题：**
- 5 个灰色方块水平排成一行
- 纯功能罗列（感知→建图→规划→交互→安全），没有"技术含量"的感觉
- 太扁平，像是 PPT 里的 SmartArt

**改造方案：✅ 保留并升级 TikZ**
- 每个节点改成圆角矩形 + 渐变色带（从蓝到青表示数据流方向）
- 节点内加小图标（Unicode 符号：📡🔍🗺️🧭🛡️）
- 箭头改成渐变色的粗箭头，带"数据流"标注
- 在下方加一条"技术栈分层"（感知层→决策层→交互层），增加纵深感

> **备选：** GPT Image 生成"数据流管道"风格的 3D 流程图，更炫酷。

---

### 🔴 TikZ #3：融资资金注入路径图 A（§4.5）

**现状问题：**
- 只有 2 个方框 + 1 个箭头
- 信息量极少，占一整行 figure 太浪费空间
- 没有"资金流动"的感觉

**改造方案：✅ 保留并丰富 TikZ**
- 上方：投资人框 + 金额标签（金色边框，金币图标）
- 中间：粗大的渐变箭头（绿色→金色），箭头上标注"300 万 全额注资"
- 下方：总公司框（深蓝色），旁边小字标注"不设分公司/关联公司"
- 背景加上浅色的盾牌或锁图标，暗示资金安全
- 整体控制在 5–6 cm 高度，不浪费太多页面

---

### 🔴 TikZ #4：公司三级垂直组织架构图 B（§4.5）

**现状问题：**
- 这是最复杂的一个 TikZ 图，但也是**最丑的**

- 连线复杂且不美观，倒 T 型结构看起来很机械
- 8 个第三层节点的对齐方式很奇怪（below right + anchor=west 的 hack）

**改造方案：🗑️ 强烈建议删除 TikZ，改用 GPT Image**

### 🔴 TikZ #5：商业模式示意图（§5.1）

**现状问题：**

- 使用双向弧形箭头（收入流 + 服务流）
- 每个圆用渐变色填充
- 可以加上金额标注（如"B 端租赁：2400 万/年"）

> **备选：** GPT Image 生成"飞轮"或"生态系统"风格的 3D 图，中心发光 + 4 个轨道环绕。

### 🔴 TikZ #6：场景部署流程示意图（§6.2）
